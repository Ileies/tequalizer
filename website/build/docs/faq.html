FAQ

Haufig gestellte Fragen zu Tequalizer.

Was kostet Tequalizer?

Die Extension selbst ist kostenlos. Du benotigst jedoch einen eigenen OpenAI API-Schlussel. Die Kosten dafur hangen von der Nutzung ab - GPT-4o mini (der Standard) ist sehr gunstig und kostet wenige Cent pro mehrseitigem Artikel.

Werden meine Daten gesammelt?

Nein. Alle Daten (API-Schlussel, Styles, Einstellungen) werden ausschliesslich lokal in deinem Browser gespeichert. Der Entwickler empfangt keine Daten. Seitentext wird direkt von deinem Browser an die OpenAI API gesendet - nicht uber einen Zwischen-Server.

Welche Browser werden unterstutzt?

Tequalizer lauft als Manifest-V3-Extension in Google Chrome, Mozilla Firefox, Microsoft Edge und Brave. Andere Chromium-basierte Browser funktionieren in der Regel ebenfalls.

Welche KI-Modelle werden unterstutzt?

Aktuell (V1) wird ausschliesslich die OpenAI API unterstutzt. In V2 folgt Anthropic Claude, in V3 Ollama fur lokale Modelle.

Warum funktioniert der Auto-Modus nicht auf manchen Seiten?

Der Auto-Modus erkennt Artikel anhand von Readability-Kriterien: Textlange, Absatzstruktur und Verhaltnis von Fliesstext zu Navigationselementen. Sehr kurze Texte, Startseiten, Suchergebnisse und layoutlastige Seiten werden nicht als Artikel erkannt und bleiben unverandert. Die Mindest-Wortanzahl kann in den Einstellungen angepasst werden.

Kann ich Tequalizer auf bestimmten Websites deaktivieren?

Ja. Im Auto-Modus-Tab der Options-Seite kannst du Domains zur Ausschlussliste hinzufugen. Auf diesen Seiten wird der Auto-Modus nicht ausgefuhrt. Der manuelle Rewrite per Popup-Klick ist weiterhin moglich.

Wie lange dauert eine Umformulierung?

Das hangt von der Lnge des Artikels und dem gewhlten Modell ab. Typischerweise 10-30 Sekunden fur einen mittellangen Artikel. Die Umformulierung lauft in Echtzeit-Streaming, sodass Segmente nach und nach erscheinen.

Was ist der Unterschied zwischen "Stil extrahieren" und den manuellen Reglern?

"Stil extrahieren" analysiert den Schreibstil einer beliebigen Webseite automatisch und ubersetzt ihn in Regler-Werte und optionale Zusatzinstruktionen. Die manuellen Regler erlauben die direkte, prazise Einstellung ohne Referenztext. Beides kann kombiniert werden: erst extrahieren, dann die Regler feinjustieren.

Wird das Original der Seite wiederhergestellt wenn ich einen Rewrite ablehne?

Ja. Im Diff-Overlay kannst du jeden Abschnitt einzeln akzeptieren oder verwerfen. Abgelehnte Abschnitte behalten den Originaltext. Ein komplettes Zurucksetzen (alle Rewrites verwerfen) ist derzeit noch nicht als eine-Klick-Aktion verfugbar, aber auf der Roadmap.

Wie melde ich einen Fehler oder schlage ein Feature vor?
