Erste Schritte

Diese Anleitung fuhrt dich von der Installation bis zur ersten Seitenumformulierung. Die gesamte Einrichtung dauert ca. 3 Minuten.

1. Extension installieren

Tequalizer ist als Manifest-V3-Extension fur Chrome und Firefox verfugbar. Lade sie aus dem jeweiligen Store:

  • Chrome, Edge, Brave: Chrome Web Store (bald verfugbar)
  • Firefox: Firefox Add-ons (bald verfugbar)

Nach der Installation erscheint das Tequalizer-Icon in der Browser-Symbolleiste. Falls es nicht sichtbar ist, klicke auf das Erweiterungs-Puzzle-Symbol und hefte Tequalizer an.

2. OpenAI API-Schlussel hinterlegen

Tequalizer nutzt die OpenAI API fur das Umformulieren. Du benotigst einen eigenen API-Schlussel von platform.openai.com.

  1. Tequalizer-Popup offnen (Extension-Icon anklicken).
  2. Wenn noch kein API-Schlussel konfiguriert ist, zeigt das Popup einen Einrichtungshinweis - auf "Einstellungen offnen" klicken.
  3. Im Tab "API & Modell" den OpenAI API-Schlussel eingeben und "Speichern" klicken.
  4. Optional: Das Modell wechseln (Standard ist GPT-4o mini).
Datenschutz: Dein API-Schlussel wird ausschliesslich lokal in browser.storage.local gespeichert. Weder der Schlussel noch Seiteninhalt werden an den Entwickler ubermittelt. Seitentext geht direkt von deinem Browser an die OpenAI API.

3. Ersten Artikel umformulieren

  1. Ruf einen Blogartikel oder Nachrichtenbeitrag auf.
  2. Offne das Tequalizer-Popup.
  3. Stelle die funf Style-Regler nach Wunsch ein (oder behalte die Standardwerte).
  4. Klicke auf "Seite umformulieren".
  5. Der Text wird im Hintergrund umformuliert und ein Diff-Overlay erscheint - Abschnitt fur Abschnitt.
  6. Im Diff-Overlay kannst du Original und Umformulierung vergleichen und jeden Abschnitt einzeln akzeptieren oder verwerfen.

4. Styles speichern und verwalten

Wenn du eine Regler-Kombination ofter nutzt, speichere sie als benannten Style:

  1. Regler wie gewunscht einstellen.
  2. Im Popup auf den Style-Namen klicken und "Als neuen Style speichern" wahlen.
  3. Einen Namen vergeben - der Style ist ab sofort in der Dropdown-Liste verfugbar.

Styles werden in der Options-Seite verwaltet (Zahnrad-Icon im Popup, dann Tab "Style-Bibliothek"). Dort kannst du Styles auch bearbeiten, loschen und einen Standard-Style festlegen.

5. Auto-Modus einrichten (optional)

Der Auto-Modus erkennt Artikel automatisch und formuliert sie beim Seitenaufruf um - ohne manuellen Klick.

  1. Options-Seite offnen (Zahnrad im Popup).
  2. Tab "Auto-Modus" wahlen.
  3. Auto-Modus aktivieren.
  4. Optional: Mindest-Wortanzahl anpassen und bestimmte Domains ausschliessen.
Hinweis: Der Auto-Modus erkennt Artikel anhand von Readability-Kriterien (Textlange, Absatzstruktur). Kurze oder layoutlastige Seiten werden nicht als Artikel erkannt und bleiben unverandert.
