Mozilla Firefox

Fur Firefox Desktop

Eigener API-Schlussel erforderlich

Tequalizer benotigt einen eigenen OpenAI API-Schlussel. Der Schlussel wird ausschliesslich lokal in deinem Browser gespeichert und nie an den Entwickler ubermittelt. Claude und Ollama folgen in V2/V3.

Schnellstart

  1. Extension im Browser-Store installieren und den Berechtigungen zustimmen.
  2. Das Tequalizer-Icon in der Symbolleiste anklicken - es erscheint ein Hinweis zur API-Konfiguration.
  3. Unter Einstellungen (Zahnrad-Icon) deinen OpenAI API-Schlussel eingeben und speichern.
  4. Einen Artikel aufrufen, das Popup offnen, Regler einstellen und "Seite umformulieren" klicken.
